# Beyond Words · 日语 · 小枝萌菜版（个人定制）

只供本人使用的商务日语练习网页，不公开。由公开日语版复制而来，但内容、题型和流程已独立。

## 练习方式

题面只给场景和意思，不给任何日语；先自己想、打字写出日语，再核对。目的是把“认识但提取不出来”的表达练到能脱口而出。

- A 定型表达（整块记住）：初试 1 题；有相近表达时学习再加 1 题辨别；复习固定 1 题。不设自建例句。
- B 框架表达（带空位）：学习 2 题（先整体回忆框架，再给具体场景）；复习 2 题。不设自建例句。
- C 可造句表达：讲解后学习 1 题，再自建 1 个例句，复习 1 题。
- 翻译未命中时有“修改再试｜我答对了”，另一行是“复制 AI 核对指令”。

## 语料库

只有一个库：小枝萌菜，按日期分单元。日期页按主题分组（头语结语、贺年卡、暑中问候、迁址更名、报价与回信、就任与调动等）。当前 2026-11-01 一天，182 个单元（A 109 / B 60 / C 13）。

## 其他功能

笔记（含格式）、自评、词语／句式提示、学习进度回看、小水獭心情打卡与学习日历、进度备份导入导出。数据只存在浏览器本地，存储键 `beyondwords.japanese.personal.v1`，备份标识 `beyondwords-japanese-personal-progress`。
